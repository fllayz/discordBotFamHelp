# Discord Bot v1.1

Многофункциональный Discord бот, написанный на Python с использованием библиотеки discord.py.

## Возможности

- Управление каналами
- Интерактивные команды
- Система логирования
- Модульная структура с использованием когов (cogs)

## Требования

- Python 3.8+
- discord.py
- python-dotenv

## Установка

1. Клонируйте репозиторий:
```bash
git clone [URL вашего репозитория]
cd discord_bot_v1.1
```

2. Установите зависимости:
```bash
pip install discord.py python-dotenv
```

3. Создайте файл `.env` и добавьте в него токен вашего бота:
```
TOKEN=ваш_токен_бота
```

## Структура проекта

```
discord_bot_v1.1/
├── main.py           # Основной файл бота
├── config.py         # Конфигурационные настройки
├── cogs/            # Директория с когами
│   ├── channel_managers.py
│   └── interactions.py
├── utils/           # Вспомогательные утилиты
└── database/        # Директория для базы данных
```

## Использование

1. Запустите бота:
```bash
python main.py
```

2. Бот использует префикс `!` для команд.

## Разработка

Бот имеет модульную структуру с использованием системы когов Discord.py. Для добавления новых функций создайте новый ког в директории `cogs/` и зарегистрируйте его в `main.py`.
